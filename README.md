# Assignment 8 - Gym & Fitness Club Management REST API


## Overview

A backend REST API for managing a Gym & Fitness Club using Node.js, Express.js, MongoDB and Mongoose.

## Features

- Member management
- Trainer management
- Membership management
- Class management
- Authentication
- Session management
- Password hashing
- Input validation
- Custom middleware
- RESTful API endpoints
- MongoDB database integration

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Passport.js
- Express Session
- dotenv

## Project Structure

All project files are organized inside the `Saiyash Poojari` folder.
